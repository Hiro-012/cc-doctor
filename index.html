cc-doctor

A Claude Code security & config scanner. Free and open source.

cc-doctor is a diagnostic CLI for repositories that use Claude Code. It scans your project's Claude Code configuration — .claude/settings.json, hooks, .mcp.json, CLAUDE.md — and your git-tracked files, flagging unrestricted permission grants, hardcoded secrets, broken hook paths, and other common misconfigurations before they cause a security or usability problem.

Install

npx cc-doctor

No account, no telemetry, runs entirely on your machine.

Free vs. Pro

Free (today)All checks: settings/permissions, MCP config secrets, CLAUDE.md hygiene, git-tracked secret scanning. MIT licensed, no limits.
Pro (planned)Not yet available. Deeper checks (dependency vulnerability scanning, broader secret patterns, team Slack/webhook alerts) and a GitHub App mode are under consideration as a future paid tier — the current CLI stays free either way.
